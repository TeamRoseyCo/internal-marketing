<objective>
Audit and fix Cumulative Layout Shift (CLS) issues from Framer Motion animations, ensure dynamic content areas have reserved space, and optimize all animated components to achieve CLS < 0.1.

Purpose: CLS is a critical Core Web Vital that affects user experience and SEO rankings. Animations that change layout (height, width) cause CLS - must use transform (y, x, scale) and opacity only.

Output: CLS-optimized components with animations that don't shift layout, achieving the < 0.1 CLS target for Core Web Vitals compliance.
</objective>

<task type="auto">
  <name>Task 3: Optimize Lenis smooth scroll with visibility handling</name>
  <files>src/components/providers/lenis-provider.tsx</files>
  <action>
  Add visibility change handler to Lenis provider to stop smooth scroll when browser tab is hidden.
  This prevents unnecessary CPU usage when the page is not visible.

  Add inside the useEffect, after the Lenis initialization:

  ```tsx
  // Stop/start Lenis based on tab visibility to save CPU
  const handleVisibilityChange = () => {
    if (document.hidden) {
      lenisInstance.stop();
    } else {
      lenisInstance.start();
    }
  };

  document.addEventListener('visibilitychange', handleVisibilityChange);
  ```

  Update the cleanup function to remove the event listener:

  ```tsx
  return () => {
    clearTimeout(timeoutId);
    document.removeEventListener('visibilitychange', handleVisibilityChange);
    window.removeEventListener("resize", handleResize);
    lenisInstance.destroy();
  };
  ```

  This optimization is recommended by the Lenis documentation and community best practices.
  </action>
  <verify>
  Read src/components/providers/lenis-provider.tsx and confirm:
  - visibilitychange event listener is added
  - lenisInstance.stop() is called when document.hidden is true
  - lenisInstance.start() is called when document becomes visible
  - Event listener is cleaned up in the return function
  </verify>
  <done>

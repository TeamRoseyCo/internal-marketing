**Part B: TableOfContents component (`src/components/content/table-of-contents.tsx`)**

Client component (`"use client"`) that extracts headings from raw markdown content and renders a clickable TOC.

```typescript
interface TableOfContentsProps {
  content: string;  // Raw markdown content string
}
```

Implementation:
1. Parse headings from markdown using regex: `/^#{2,3}\s+(.+)$/gm` (h2 and h3 only, skip h1)
2. Generate IDs by lowercasing and replacing non-alphanumeric chars with hyphens
3. Track active heading using IntersectionObserver (rootMargin: '-100px 0px -66%')
4. Render as nav with "Table of Contents" heading
5. h3 headings indented (ml-4) under h2 headings
6. Active heading highlighted with text-primary and font-medium
7. Inactive headings use text-muted-foreground
8. Links use `href={`#${heading.id}`}` for smooth scroll to anchor
9. Wrap in a card-style container: p-6 bg-muted/30 rounded-lg border border-border mb-12

**Important:** This component reads headings from the raw markdown string (before MDX rendering). The heading IDs must match what rehype-slug generates. Since we are NOT installing rehype-slug (it's not in package.json and we shouldn't add deps unnecessarily), we need to add `id` attributes to the MDX heading components instead.

**Approach:** Rather than relying on rehype-slug, update the heading components in `mdx-components.tsx` to auto-generate IDs. BUT this plan should NOT modify mdx-components.tsx (that file is touched in Plan 03). Instead, the TOC component should include a note/comment that heading IDs are generated by mdx-components.tsx heading elements.

The TOC component extracts heading text and generates slug IDs. The mdx-components.tsx heading elements (modified in Plan 03) will add matching `id` attributes to rendered headings.

ID generation function (shared logic - define in the component, will be extracted to util if needed):
```typescript
function generateHeadingId(text: string): string {
  return text
    .toLowerCase()
    .replace(/[^a-z0-9\s-]/g, '')
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-|-$/g, '');
}
```

Return null if no headings found (don't render empty TOC).

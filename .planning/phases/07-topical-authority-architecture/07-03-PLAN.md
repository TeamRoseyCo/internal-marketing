**Part A: Pillar page dynamic route (`src/app/[locale]/[pillarSlug]/page.tsx`)**

Create the pillar page route following the exact pattern of `src/app/[locale]/blog/[slug]/page.tsx`. This is the core rendering page.

**CRITICAL ROUTING NOTE:** Next.js [locale] is already a catch-all dynamic segment. Adding [pillarSlug] as a sibling segment means `/us/seo-guide` could match either [locale]/[pillarSlug] or be interpreted as [locale]/blog etc. Since there are specific folders for blog, services, contact, results, privacy-policy under [locale], the [pillarSlug] catch-all will only match slugs that DON'T match those folders. This works because pillar slugs are distinct (seo-guide, paid-ads-guide, etc.).

However, we need to validate that the pillarSlug is actually a valid pillar to avoid catching unrelated 404 routes. In `generateStaticParams`, only return actual pillar slugs. In the page component, call `getPillarBySlug` and `notFound()` if null.

**Implementation:**

```typescript
// generateStaticParams
export async function generateStaticParams() {
  const params: { locale: string; pillarSlug: string }[] = [];
  for (const locale of localeList) {
    const slugs = getPillarSlugs(locale);
    for (const slug of slugs) {
      params.push({ locale, pillarSlug: slug });
    }
  }
  return params;
}
```

```typescript
// generateMetadata
export async function generateMetadata({ params }: Props) {
  const { locale, pillarSlug } = await params;
  const localeCode = isValidLocale(locale) ? locale : 'us';
  const pillar = getPillarBySlug(pillarSlug, localeCode);
  if (!pillar) return { title: 'Not Found' };

  return {
    title: pillar.title,
    description: pillar.excerpt,
    openGraph: {
      title: pillar.title,
      description: pillar.excerpt,
      type: 'article',
      publishedTime: pillar.date,
      modifiedTime: pillar.dateModified || pillar.date,
      authors: [pillar.author],
      locale: getOpenGraphLocale(localeCode),
    },
    alternates: generateHreflangAlternates(localeCode, `/${pillarSlug}`),
  };
}
```

```typescript
function generateHeadingId(children: React.ReactNode): string {
  const text = typeof children === 'string'
    ? children
    : Array.isArray(children)
      ? children.map(c => typeof c === 'string' ? c : '').join('')
      : '';
  return text
    .toLowerCase()
    .replace(/[^a-z0-9\s-]/g, '')
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-|-$/g, '');
}
```

Update each heading component to include the `id` attribute:

```typescript
h2: ({ children }) => (

),
```

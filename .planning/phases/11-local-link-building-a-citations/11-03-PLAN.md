Create a detailed submission guide document with step-by-step instructions for each Tier 1 directory.

**For EACH of the 14 Tier 1 directories, create a guide section containing:**

1. **Directory name and URL**
2. **Submission/Claim URL** (direct link to the "add business" or "claim" page)
3. **Account requirements** (email, phone verification, postcard, etc.)
4. **Step-by-step instructions** (numbered steps with exact field names)
5. **NAP fields** (exactly what to enter in each field -- copy from authoritative NAP)
6. **Business description** (which length to use: 50/100/250 words based on directory limits)
7. **Categories to select** (prioritized: "Digital Marketing Agency" > "Marketing Agency" > "Advertising Agency" > "SEO Agency")
8. **Photos to upload** (logo, office exterior if available, team if available)
9. **Verification method** (email, phone, postcard, instant)
10. **Expected timeline** (how long until listing goes live)
11. **Common issues** (what can go wrong and how to fix)

**Guide order (submission priority from citation-tracker.md):**

1. **Google Business Profile** -- Verify existing listing matches authoritative NAP; check all fields are complete (hours, categories, description, photos, website URL). URL: https://business.google.com/
2. **Foursquare** -- Critical for AI search. Claim at https://foursquare.com/. Fully optimize: photos, hours, description, all categories. URL to list: roseyco.com/uk/belfast/
3. **Apple Maps (Apple Business Connect)** -- https://businessconnect.apple.com/. Requires Apple ID. Upload logo, set hours, verify NAP.
4. **Bing Places** -- https://www.bingplaces.com/. Can import from GBP to save time. Verify independently.
5. **Facebook Business Page** -- Create if not exists, or verify NAP on existing page. Set as "Marketing Agency" category.
6. **Yell.com** -- https://www.yell.com/. Free listing available. Enter all NAP fields exactly.
7. **Thomson Local** -- https://www.thomsonlocal.com/. Free listing. May require phone verification.
8. **Scoot.co.uk** -- https://www.scoot.co.uk/. Syndicates to 6+ directories (high value per submission).
9. **192.com** -- https://www.192.com/. Business listing section.
10. **Yelp UK** -- https://www.yelp.co.uk/. Claim or create business listing. Upload photos.
11. **Golden Pages Ireland** -- https://www.goldenpages.ie/. Cross-border visibility for IE locale.
12. **Clutch.co** -- https://clutch.co/. Marketing agency directory. Create company profile.
13. **Belfast Chamber** -- Enquiry template provided. Requires membership decision.
14. **NI Chamber** -- Enquiry template provided. Requires membership decision.

**For chambers (13-14), provide:**
- Enquiry email template (short, professional)
- Questions to ask: membership cost, directory listing included?, backlink type (dofollow/nofollow), member benefits
- Decision criteria: worth joining if directory listing includes dofollow link AND membership cost < GBP 500/year

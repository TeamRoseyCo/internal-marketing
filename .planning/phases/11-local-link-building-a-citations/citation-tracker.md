# Citation Submission Workflow

## Step-by-Step Process for Each Directory

1. **Prepare Materials Before Starting:**
   - Authoritative NAP copied and ready to paste
   - Business descriptions (50/100/250 words) in clipboard
   - High-quality photos ready (logo, office, team, work examples)
   - Social media profile URLs ready
   - Categories/keywords list ready

2. **For Each Directory:**
   - [ ] Visit submission URL
   - [ ] Create account or log in
   - [ ] Search for existing listing (claim if exists)
   - [ ] Fill in NAP using EXACT authoritative format
   - [ ] Paste appropriate business description (check character limit)
   - [ ] Select categories (use primary categories first)
   - [ ] Add opening hours (Mon-Fri 9:00-17:00)
   - [ ] Upload photos (minimum 5, ideal 10+)
   - [ ] Add services list if available
   - [ ] Add social media links
   - [ ] Add website URL (https://roseyco.com/uk/)
   - [ ] Add Belfast page URL (https://roseyco.com/uk/belfast/)
   - [ ] Save and submit for verification
   - [ ] Complete verification process (email/phone/postcard)
   - [ ] Update this tracker with submission date
   - [ ] Save login credentials securely

3. **After Submission:**
   - [ ] Update citation tracker status
   - [ ] Set calendar reminder for verification follow-up (1 week)
   - [ ] Monitor email for verification instructions
   - [ ] Complete verification promptly

4. **After Verification:**
   - [ ] Update tracker with verification date
   - [ ] Screenshot completed profile
   - [ ] Check listing is live and NAP displays correctly
   - [ ] Add to quarterly audit checklist

# Notes Section

**Tips for Efficient Citation Building:**

- Batch similar directories together (all Cylex sites, all agency directories, etc.)
- Use password manager to store login credentials
- Take screenshots of completed profiles for records
- Set up email folder for citation verification emails
- Use calendar reminders for verification follow-ups
- Don't rush - accuracy > speed for NAP consistency
- Foursquare is non-negotiable (AI search critical)
- Google Business Profile optimization is ongoing, not one-time

**Common Verification Methods:**
- Email: Check inbox and spam folder
- Phone: Automated call with verification code
- Postcard: 5-14 business days to 1 Hollycroft Avenue
- Business documents: Upload proof of business registration

**If Verification Fails:**
- Check NAP matches exactly across all fields
- Verify phone number can receive calls/SMS
- Verify email address is correct and receiving emails
- Contact directory support for manual verification

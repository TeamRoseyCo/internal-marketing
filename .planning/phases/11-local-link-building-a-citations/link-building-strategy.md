**Purpose:** Prioritized 12-week action plan for acquiring locally-relevant links and citations
**Created:** 2026-02-11
**Status:** Ready for execution

## Strategy Overview

**Goal:** Build locally-relevant link profile for Belfast market dominance in local search

**Core Principle:** Local relevance > Domain Authority
- Belfast Chamber (DA ~45) > Generic directory (DA 80) for Belfast local rankings
- Links from Belfast sources signal community integration and local authority
- Quality and relevance matter more than volume in 2026

**Timeline:** 12-week rolling strategy
- **Weeks 1-4:** Foundation (citations, verification, setup)
- **Weeks 5-8:** Active outreach (media, partnerships)
- **Weeks 9-12:** Relationship building (ongoing partnerships, community involvement)

## Priority 3: Media Links (Weeks 5-8)

**Objective:** Earn high-authority media backlinks through HARO responses and proactive Belfast media outreach

### HARO (Help a Reporter Out) - Ongoing

**Strategy:** Passive link building through journalist query responses

**Implementation:**
1. **Daily monitoring (ongoing from Week 4)**
   - Review HARO queries 3x daily (morning, afternoon, evening)
   - Filter for relevant topics:
     - Belfast/Northern Ireland business topics
     - Digital marketing industry queries
     - SMB marketing strategies
     - Local SEO topics

2. **Response criteria**
   - Only respond to queries where genuine expertise exists
   - Can provide specific examples, data, or case studies
   - Query matches HARO templates A, B, or C from outreach-templates.md

3. **Response process**
   - Respond within 2 hours of query publication (highest acceptance rate)
   - Customize template heavily for each query (never copy-paste)
   - Include Belfast-specific examples when relevant
   - Provide concrete data and metrics (not generic advice)
   - Never use AI to generate response (HARO detects and bans)

4. **Success tracking**
   - Track: Queries responded to, pitches accepted, links earned
   - Goal: 2-3 HARO links earned within 12 weeks (10-20% acceptance rate)
   - Celebrate: Each HARO link typically high-DR (70-95) media backlink

**Time commitment:** 15-30 minutes daily for query review and response

### Media Outreach Best Practices

**Do:**
- Lead with story angle, not "please feature my business"
- Offer genuine value: data, expert quotes, Belfast case studies
- Research journalist's recent articles before pitching
- Pitch Tuesday-Thursday mornings (best response rates)
- Be responsive if journalist follows up (they work on tight deadlines)

**Don't:**
- Pitch same publication more than once per month (avoid spam folder)
- Send generic mass pitches (personalize for each publication)
- Follow up more than once (respect journalists' time)
- Pitch irrelevant or purely promotional content

## What NOT to Do

**Anti-patterns to avoid:**

### ❌ Don't Buy Links from Fiverr or Link Farm Services
- **Why:** Paid links from irrelevant sources are penalized by Google
- **Instead:** Earn editorial links through valuable content and relationships

### ❌ Don't Submit to 100+ Low-Quality Directories
- **Why:** Mass directory submissions waste time and provide minimal benefit in 2026
- **Instead:** Focus on 14 Tier 1 + 20-25 Tier 2 high-authority sources

### ❌ Don't Use AI to Generate HARO Responses
- **Why:** HARO now detects and bans AI-generated pitches
- **Instead:** Write genuine expert responses based on real experience

### ❌ Don't Pursue Excessive Reciprocal Link Exchanges
- **Why:** A↔B link schemes are flagged by Google (you link to me, I link to you repeatedly)
- **Instead:** Build genuine partnerships with natural contextual linking

### ❌ Don't Chase High-DA Generic Links Over Lower-DA Belfast Links
- **Why:** Local relevance matters more than generic authority for local rankings
- **Instead:** Prioritize Belfast Chamber (DA 45) over generic directory (DA 80)

### ❌ Don't Neglect Existing Citations
- **Why:** Outdated NAP information harms rankings and confuses customers
- **Instead:** Schedule quarterly citation audits and update when business details change

### ❌ Don't Build New Citations Before Auditing Existing Ones
- **Why:** Inconsistent NAP across old and new listings confuses search engines
- **Instead:** Audit and fix existing listings first, then build new ones with consistent NAP

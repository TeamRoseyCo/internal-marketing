<task type="auto">
  <name>Task 2: Convert Footer component to use translation hooks</name>
  <files>
    src/components/layout/footer.tsx
  </files>
  <action>
Refactor footer.tsx to use i18n hooks:

1. **Replace locale detection:**
   - Remove: `const pathname = usePathname();`
   - Remove: `const currentLocale = pathname.split('/')[1];`
   - Remove: `const locale = isValidLocale(currentLocale) ? currentLocale : null;`
   - Add: `import { useLocale, useTranslation } from "@/lib/i18n";`
   - Add: `const locale = useLocale();`
   - Add: `const { t } = useTranslation();`

2. **Remove hardcoded baseFooterLinks:**
   Replace static arrays with translation-based generation:
   ```typescript
   const footerLinks = {
     services: [
       { href: `/${locale}/services/seo`, label: t("footer.services.seo") },
       { href: `/${locale}/services/social-media`, label: t("footer.services.socialMedia") },
       { href: `/${locale}/services/paid-ads`, label: t("footer.services.paidAds") },
       { href: `/${locale}/services/website-design`, label: t("footer.services.webDesign") },
     ],
     company: [
       { href: `/${locale}/results`, label: t("footer.company.results") },
       { href: `/${locale}/blog`, label: t("footer.company.blog") },
       { href: `/${locale}/contact`, label: t("footer.company.contact") },
       { href: `/${locale}/privacy-policy`, label: t("footer.company.privacy") },
     ],
   };
   ```

3. **Update section headings:**
   - Services column: `<h3>` text from "Services" to `{t("footer.headings.services")}`
   - Company column: `<h3>` text from "Company" to `{t("footer.headings.company")}`
   - Contact column: `<h3>` text from "Contact" to `{t("footer.headings.contact")}`

4. **Update brand description:**
   - Replace hardcoded: "We help businesses worldwide generate more customers..."
   - With: `{t("footer.brandDescription")}`

5. **Update bottom bar:**
   - Copyright: Keep year dynamic, translate the rest: `{new Date().getFullYear()} Rosey Co. {t("footer.copyright")}`
   - Tagline: Replace "Global Social Media Marketing Agency" with `{t("footer.tagline")}`

6. **Remove unused imports:**
   - Remove usePathname if no longer used
   - Remove isValidLocale if no longer used

Keep all styling, animations, social links, and layout unchanged. Only text and locale detection changes.

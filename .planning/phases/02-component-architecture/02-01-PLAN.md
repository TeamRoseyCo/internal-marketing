   - Add "use client" directive
   - Import useLocaleContext from ./context
   - Import getTranslations from @/lib/translations

   - Create useLocale() hook:
     - Call useLocaleContext()
     - Return locale from context

   - Create useTranslation() hook:
     - Get locale from useLocale()
     - Get translations via getTranslations(locale)
     - Return t() function that:
       - Takes key string (e.g., "nav.services")
       - Splits key by "." and traverses object
       - If key not found in development: console.warn with key and locale
       - If key not found: fallback to English (getTranslations("us"))
       - If still not found: return the key itself as fallback
     - Return { t, locale } for convenience

2. **src/lib/i18n/formatters.ts** - Currency formatting:
   - Import LocaleCode, locales from @/lib/locales

   - Create formatCurrency(amount: number, locale: LocaleCode): string
     - Get languageCode, countryCode, currency from locales[locale]
     - Use Intl.NumberFormat with:
       - Locale: `${languageCode}-${countryCode}`
       - Style: "currency"
       - Currency: currency from config
     - Return formatted string

   - Test expectations per RESEARCH.md:
     - US: "$1,299.00"
     - UK: "£1,299.00"
     - NL: "€ 1.299,00" (European format with space)
     - DK: "1.299,00 kr." (Danish krone format)

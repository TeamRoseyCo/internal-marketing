<task type="auto">
  <name>Task 2: Convert Header component to use translation hooks</name>
  <files>
    src/components/layout/header.tsx
  </files>
  <action>
Refactor header.tsx to use i18n hooks:

1. **Replace locale detection:**
   - Remove: `const pathname = usePathname();`
   - Remove: `const currentLocale = pathname.split('/')[1];`
   - Remove: `const locale = isValidLocale(currentLocale) ? currentLocale : null;`
   - Add: `import { useLocale, useTranslation } from "@/lib/i18n";`
   - Add: `const locale = useLocale();`
   - Add: `const { t } = useTranslation();`

2. **Update baseNavItems to use translations:**
   Replace the static baseNavItems array with dynamic generation:
   ```typescript
   const navItems = [
     { href: `/${locale}`, label: t("header.home") },
     { href: `/${locale}/services`, label: t("nav.services") },
     { href: `/${locale}/results`, label: t("nav.results") },
     { href: `/${locale}/blog`, label: t("nav.blog") },
     { href: `/${locale}/contact`, label: t("nav.contact") },
   ];
   ```
   Note: locale is ALWAYS defined now (from context), so no need for conditional URL building.

3. **Update CTA button text:**
   - Desktop CTA: Change "Get More Leads" to `{t("header.cta")}`
   - Mobile CTA: Same change in MobileMenu component

4. **Update MobileMenu component:**
   - MobileMenu receives navItems as prop (already translated)
   - Update the CTA button in MobileMenu to use translated text
   - Pass t function or cta text as prop to MobileMenu

5. **Remove unused imports:**
   - Remove usePathname import if no longer used
   - Remove isValidLocale import if no longer used

Keep all styling, animations, and layout unchanged. Only text and locale detection changes.
  </action>

## Validation Rules

### Rule 1: One Primary Keyword Per URL
**Principle:** Each URL has exactly ONE primary target keyword. Secondary keywords can overlap if intent differs.

**✅ Valid:**
- `/uk/seo-belfast/` targets "SEO Belfast" (primary)
- `/uk/seo-belfast/` also targets "SEO agency Belfast" (secondary, same intent)
- `/uk/blog/local-seo-belfast/` targets "local SEO Belfast" (different niche)

**❌ Invalid (Cannibalization):**
- `/uk/seo-belfast/` targets "SEO Belfast" (commercial)
- `/uk/services/seo/` targets "SEO Belfast" (commercial) ← CONFLICT!

**Fix:** Differentiate by intent or location:
- `/uk/seo-belfast/` = Belfast-specific commercial (local focus, Belfast pricing, Belfast case studies)
- `/uk/services/seo/` = Global service description (6 locales, company-wide offering)

---

### Rule 2: Related Keywords Can Appear on Multiple Pages IF Intent Differs

**✅ Valid (No cannibalization):**
- "SEO Belfast" on `/uk/seo-belfast/` (Commercial/Transactional intent - service offering with CTA)
- "How to rank on Google Belfast" on `/uk/blog/how-to-rank-on-google-belfast/` (Informational intent - educational guide)

**Rationale:** Different user journey stages. Commercial user wants to hire. Informational user wants to learn.

**❌ Invalid (Cannibalization):**
- "SEO Belfast" on `/uk/seo-belfast/` (Commercial - hire us)
- "SEO Belfast" on `/uk/belfast-seo-services/` (Commercial - hire us) ← SAME INTENT!

---

### Rule 3: Secondary Keywords Support Primary, Don't Compete

**✅ Valid:**
- Primary: "SEO Belfast" on `/uk/seo-belfast/`
- Secondary: "SEO agency Belfast", "SEO services Belfast" (synonyms/variations, same intent)

**❌ Invalid:**
- Primary: "SEO Belfast" on `/uk/seo-belfast/`
- Secondary: "local SEO Belfast" (different niche deserving own cluster page)

**Fix:** Give "local SEO Belfast" its own cluster page with distinct angle.

---

### Rule 4: Flag Potential Cannibalization Risks

**Cannibalization risk indicators:**
- Same keyword + same intent + different URLs = ⚠️ HIGH RISK
- Same keyword + different intent + different URLs = ✅ OK (intent differentiation)
- Related keyword + same intent + different URLs = ⚠️ MEDIUM RISK (consider merging)

**Current risks in map:**
- ❌ None detected (architecture designed to prevent)

## Usage Instructions

### When Creating New Content

**Step 1: Check if keyword exists in map**
```bash
# Search for keyword
grep -i "keyword phrase" belfast-keyword-map.md
```

**Step 2: If keyword found:**
- Check assigned URL
- Check search intent
- If intent matches: Add content to existing page (don't create new)
- If intent differs: Create new page with differentiation strategy

**Step 3: If keyword NOT found:**
- Add new row to mapping table
- Assign to appropriate cluster or create new cluster
- Document search intent
- Ensure no cannibalization with existing pages

**Step 4: Update mapping table**
- Add new keyword-URL pair
- Validate against rules above
- Commit changes to git

## Search Intent Definitions

### Commercial/Transactional (40% of Belfast keywords)
**User goal:** Hire a service, buy a product
**Keywords:** "agency", "services", "hire", "cost" + location
**Content type:** Service pages, pillar pages
**CTA:** Strong (quote, consultation, audit)
**Example:** "SEO agency Belfast" → wants to hire SEO agency

### Commercial Research (30%)
**User goal:** Compare options, evaluate providers
**Keywords:** "best", "top", "review", "vs", "compare"
**Content type:** Comparison content, pillar pages with credentials
**CTA:** Medium (case studies, portfolio, testimonials)
**Example:** "best SEO agency Belfast" → comparing agencies before hiring

### Informational (25%)
**User goal:** Learn, understand, educate self
**Keywords:** "how to", "what is", "guide", "tips", "why"
**Content type:** Blog posts, educational guides
**CTA:** Soft (newsletter, download, related articles)
**Example:** "how to rank on Google Belfast" → learning SEO basics

### Navigational (5%)
**User goal:** Find specific company/brand
**Keywords:** Brand name + location
**Content type:** Homepage, about page, GBP
**CTA:** Contact, learn more
**Example:** "Rosey Co Belfast" → looking for our company

## Keyword Priority Scoring

### High Priority
- ✅ Aligns with core service (SEO, social media, Google Ads, web design)
- ✅ Commercial/transactional intent
- ✅ Manageable competition (not dominated by enterprises)
- ✅ Belfast-specific (not UK-wide generic)
- ✅ SMB-relevant (£500-2000/month budget segment)

### Medium Priority
- ✅ Supports pillar content (cluster pages)
- ✅ Commercial research or specific niche
- ✅ Long-tail variations
- ✅ Platform/service-specific

### Low Priority
- ✅ Purely informational (top-of-funnel)
- ✅ Very niche or specialized
- ✅ Low relevance to core services
- ✅ Future expansion keywords

## Content Type Definitions

### Pillar (2500-3000 words)
- Comprehensive service offering page
- Commercial/transactional intent
- Links to 5-8 cluster pages
- Strong CTA, pricing, case studies
- Schema: LocalBusiness + Service

### Cluster (1000-1500 words)
- Specific aspect of pillar topic
- Mixed intent (commercial niche, educational)
- Links back to pillar, 2-3 lateral links
- Medium CTA
- Schema: Article + Breadcrumb

### Blog (1200-2000 words)
- Educational or comparison content
- Informational or commercial research intent
- Links to relevant pillars/clusters
- Soft CTA
- Schema: Article

### Service (varies)
- Global service description (6 locales)
- Not Belfast-specific
- Company-wide offering

### GBP (Google Business Profile)
- Optimized for "near me" searches
- Not a page, but GBP listing optimization
- 46% of Belfast searches use "near me"

## Cannibalization Prevention Checklist

Before creating new Belfast content:

- [ ] Search keyword in this mapping table
- [ ] Check if URL already assigned
- [ ] Verify search intent differs from existing pages
- [ ] Confirm no exact match keyword + intent combination exists
- [ ] Add new mapping if creating new page
- [ ] Document intent differentiation strategy
- [ ] Commit mapping table update to git

**If potential cannibalization detected:**
1. **Option A:** Merge content into existing page (strengthen it)
2. **Option B:** Differentiate by intent (commercial vs informational)
3. **Option C:** Differentiate by niche (general SEO vs local SEO)

**Never create two pages targeting:**
- Same keyword
- Same search intent
- Same target audience

## Quick Reference: Common Cannibalization Fixes

| Scenario | Problem | Solution |
|----------|---------|----------|
| Two commercial pages, same keyword | Intent overlap | Merge into one stronger page OR differentiate by niche |
| Pillar + cluster, similar keywords | Competing authority | Ensure cluster links to pillar, different angle |
| Old service page + new pillar | Duplicate content | Update service page to be global, pillar to be Belfast-specific |
| Multiple blogs, related keywords | Diluted authority | Consolidate into comprehensive guide, 301 redirect others |
| GBP + location page, same keyword | "Near me" conflict | GBP handles "near me", location page handles specific queries |

Create a monitoring playbook document covering:

**1. Review Cadence**

Define three review cycles with specific actions:

a. **Weekly Review (15 minutes, every Monday)**
   Checklist:
   - [ ] Check GSC for new indexing errors on Belfast pages
   - [ ] Review GA4 Belfast conversion events (phone, form, directions) - any anomalies?
   - [ ] Check GBP Insights for new search queries and customer actions
   - [ ] Review any new Google reviews and respond within 24 hours
   - [ ] Quick check: Are Belfast pages still indexed? (site:roseyco.com/uk/belfast)
   - [ ] Note: Record key numbers in tracking spreadsheet

b. **Monthly Review (45 minutes, first Monday of month)**
   Checklist:
   - [ ] Compare Belfast keyword positions vs last month (GSC Performance report, 28 days vs prior 28 days)
   - [ ] Analyze top growing and declining Belfast queries
   - [ ] Review Belfast page traffic trends (GA4, month over month)
   - [ ] Check conversion rate changes (form submissions / sessions)
   - [ ] Review competitor positions for top 5 Belfast keywords
   - [ ] Update Looker Studio dashboard screenshots for records
   - [ ] Identify 2-3 content optimization opportunities (high impressions, low CTR queries)
   - [ ] Check citation tracker for any new directory listings needed
   - [ ] Assess whether paid tool upgrade is warranted based on client count

c. **Quarterly Review (2 hours, every 3 months)**
   Checklist:
   - [ ] Full competitive analysis: Compare current positions vs Digital 24, ProfileTree, VINDICTA, Rapid Agency, Loud Mouth Media
   - [ ] Review overall Belfast SEO ROI (revenue from Belfast clients vs time/cost invested)
   - [ ] Evaluate content strategy effectiveness: Which pillars/clusters drive most traffic?
   - [ ] Assess link building impact: New backlinks acquired, domain authority changes
   - [ ] Review and update keyword targets based on actual search volume data
   - [ ] Plan next quarter's content calendar
   - [ ] Decision: Continue current strategy, adjust focus, or expand to new NI areas?

**2. Alert Response Procedures**

Define specific playbooks for common alert scenarios:

a. **Ranking Drop Alert (position drops 5+ places for tracked keyword)**
   1. Check GSC for manual actions or security issues
   2. Review recent content changes to affected pages (git log)
   3. Check for Google algorithm update announcements (Search Engine Roundtable, Google Search Central blog)
   4. Inspect affected page: Is it still indexed? Has content changed? Are internal links intact?
   5. Check competitor: Did they publish new content or acquire links?
   6. Action plan: If content issue -> fix content. If competitor -> create better content. If algo update -> wait 2 weeks and reassess.

b. **Traffic Drop Alert (30%+ decline week-over-week on Belfast pages)**
   1. Verify tracking is working (check GA4 real-time report, visit Belfast page yourself)
   2. Check for site-wide issues: Is the entire site affected or just Belfast pages?
   3. Review GSC Coverage report for new errors
   4. Check server status and page load times
   5. Look for seasonal patterns (holidays, school terms)
   6. If isolated to Belfast: Check individual page performance, look for de-indexing

c. **Conversion Drop Alert (50%+ decline in phone/form events)**
   1. Test the conversion paths manually (click phone number, submit test form)
   2. Check if tracking code is still firing (browser dev tools -> Network tab -> search for "gtag")
   3. Verify GA4 event configuration hasn't changed
   4. Check for UI/UX changes that may have affected conversion elements
   5. Compare mobile vs desktop conversion rates

d. **New Competitor Alert (new business appearing in local pack)**
   1. Check their GBP listing: reviews, photos, categories, description
   2. Analyze their website: content depth, page count, backlink profile
   3. Check if they're running paid ads on your target keywords
   4. Assess threat level: Are they targeting same Belfast SMB market?
   5. Action: If serious threat, accelerate content production or consider targeted paid campaigns

**3. Competitive Tracking Framework**

Define the 5 key Belfast competitors to monitor (from Phase 6 research):
   1. Digital 24 - 105 Google reviews, strong GBP presence, enterprise focus
   2. ProfileTree - Large blog (200+ posts), strong content marketing
   3. VINDICTA Digital - Premium positioning, awards-focused
   4. Rapid Agency Belfast - Local SEO specialist
   5. Loud Mouth Media - PPC specialist, Belfast based

For each competitor, track monthly:
   - Google ranking for top 5 shared keywords
   - GBP review count and rating
   - New content published (blog posts, pages)
   - Social media activity level
   - Any new services or market positioning changes

List the priority keywords to monitor from Phase 6 research, categorized:

a. **Primary (track weekly):** 5-7 highest commercial value keywords
   - seo belfast, social media marketing belfast, digital marketing belfast, website design belfast, paid ads belfast

b. **Secondary (track monthly):** 10-15 supporting keywords
   - local seo belfast, google ads belfast, facebook marketing belfast, ppc belfast, etc.

c. **Long-tail (track quarterly):** Cluster post target keywords
   - small business seo belfast, ecommerce website belfast, etc.

Include target positions for each keyword at 3-month, 6-month, and 12-month horizons.

c. **Quarterly Strategy Review** (2-3 pages)
   - Format: Quarter summary, KPI dashboard summary, competitive landscape changes, content performance analysis, recommendations for next quarter

Format: Clean markdown with checklists, tables, and clear section headers.

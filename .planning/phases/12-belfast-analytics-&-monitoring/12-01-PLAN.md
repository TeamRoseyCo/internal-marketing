  <action>
1. Create `src/types/gtag.d.ts` with TypeScript declarations for `window.gtag` and `window.dataLayer`. Declare gtag as a function accepting ('event', eventName: string, params?: Record<string, unknown>) and ('config', id: string, params?: Record<string, unknown>) and ('js', date: Date). Also extend the Window interface.

2. Create `src/lib/analytics.ts` with these exports:
   - `trackEvent(eventName: string, params?: Record<string, unknown>)` - Base function that safely calls window.gtag with guard check (typeof window !== 'undefined' && window.gtag). This is the foundation all other functions use.
   - `trackPhoneClick(phoneNumber: string, location: string, source: string)` - Calls trackEvent with event name 'phone_call_click' and params {phone_number, location, click_source, page_path: window.location.pathname}
   - `trackFormSubmission(formType: string, service: string, locale: string)` - Calls trackEvent with 'form_submission' and params {form_type, service_selected, locale, page_path}
   - `trackDirectionRequest(address: string, businessName: string)` - Calls trackEvent with 'direction_request' and params {business_name, business_address, location: 'Belfast', page_path}
   - All functions must be 'use client' compatible but the file itself should NOT have 'use client' directive since it's a utility library (functions are called from client components)

3. Create `src/components/analytics/tracked-phone.tsx` (client component with 'use client'):
   - Props: { number: string, displayText?: string, location?: string, source?: string, className?: string, children?: React.ReactNode }
   - Renders an `<a href="tel:...">` that calls trackPhoneClick onClick
   - Strip spaces from number for href: number.replace(/\s/g, '')
   - Display: children || displayText || number
   - Default location: 'Belfast', default source: 'unknown'

4. Create `src/components/analytics/tracked-directions.tsx` (client component with 'use client'):
   - Props: { address: string, businessName?: string, className?: string, children?: React.ReactNode }
   - Renders a button that calls trackDirectionRequest onClick, then opens Google Maps: `https://www.google.com/maps/dir/?api=1&destination=${encodeURIComponent(address)}`
   - Use window.open(url, '_blank')
   - Default businessName: 'Rosey Co. Belfast'

5. Update `src/components/analytics/index.ts` to add exports for TrackedPhone and TrackedDirections (keep existing GoogleAnalytics, MicrosoftClarity, MetaPixel exports).

IMPORTANT: Do NOT use the 'use client' directive in analytics.ts utility file. Only use it in the .tsx component files. The utility functions will be called from within client components.

IMPORTANT: The existing GoogleAnalytics component uses `NEXT_PUBLIC_GA_ID` (not `NEXT_PUBLIC_GA4_ID`). Keep consistent with this naming.

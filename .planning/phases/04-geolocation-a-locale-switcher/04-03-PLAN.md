<task type="auto">
  <name>Task 2: Create CookieConsent component</name>
  <files>src/components/cookie-consent.tsx</files>
  <action>
Create a client component for GDPR cookie consent with these features:

1. **Props interface:**
   - `userCountry?: string` - Country code from geolocation (passed from server)
   - No props needed if detecting EU from locale

2. **State management:**
   - `showBanner: boolean` - Whether to display the banner
   - Check localStorage for 'cookie-consent' value on mount
   - Values: 'accepted', 'declined', or absent

3. **EU detection logic:**
   - Import isEUCountry from '@/lib/geo-utils'
   - Determine if current locale is EU (nl, dk, ie)
   - Alternative: Accept country code prop from server

4. **Display logic:**
   - Show banner if: EU locale/country AND no consent stored
   - Hide banner if: Non-EU OR consent already given

5. **Accept handler:**
   - Store 'accepted' in localStorage: `localStorage.setItem('cookie-consent', 'accepted')`
   - Hide banner
   - Note: NEXT_LOCALE cookie is already functional (set by middleware/switcher)

6. **Decline handler:**
   - Store 'declined' in localStorage
   - Hide banner
   - Note: Site still works, just disclosed that cookies exist

7. **UI design:**
   - Fixed position bottom of viewport (z-50 or higher)
   - Dark theme matching site (bg-card/90 with backdrop-blur)
   - Subtle top border gradient (like footer)
   - Max-width container, centered content
   - Two buttons: Accept (primary/magenta), Decline (ghost/secondary)
   - Link to privacy policy (optional)

8. **Translations:**
   - Use useTranslation() hook to get t() function
   - Access translations via t('cookieConsent.title'), etc.
   - Fall back to English if context unavailable (same pattern as Header)

9. **Animation:**
   - Use framer-motion for slide-up entrance
   - Fade out on dismiss

Layout:
```
[----------------------------------------------------------]
|                                                          |
|  Cookie Notice                                           |
|  We use cookies to remember your locale preference...    |
|                                                          |
|                        [Decline]  [Accept]               |
|                                                          |
[----------------------------------------------------------]
```

<objective>
Implement GDPR-compliant cookie consent banner for EU locale visitors (Netherlands, Denmark, Ireland).

Purpose: GDPR requires informing users about cookies. While the NEXT_LOCALE cookie is classified as "strictly necessary" (and thus does not require consent), displaying a banner for EU visitors demonstrates GDPR compliance and builds user trust. Banner displays only for visitors on EU locales (locale-based detection, not IP-based geolocation).

Output: Cookie consent banner component that shows for EU locale visitors, allows accept/decline, stores consent in localStorage, and integrates with locale layout.
</objective>

<task type="auto">
  <name>Task 2: Create CookieConsent component</name>
  <files>src/components/cookie-consent.tsx</files>
  <action>
Create a client component for GDPR cookie consent with these features:

1. **Props interface:**
   - No props needed - component detects EU from locale

2. **State management:**
   - `showBanner: boolean` - Whether to display the banner
   - Check localStorage for 'cookie-consent' value on mount
   - Values: 'accepted', 'declined', or absent

3. **EU detection logic (CRITICAL - uses locale, not geolocation headers):**
   - Import `isEULocale` from '@/lib/geo-utils' (created in 04-01)
   - Get current locale via `useLocale()` hook from '@/lib/i18n'
   - Call `isEULocale(locale)` to determine if EU
   - This works because:
     a) EU_LOCALES is defined as ['nl', 'dk', 'ie'] in geo-utils.ts
     b) No geolocation headers needed - locale alone determines EU status
     c) Client component has access to locale via context

4. **Display logic:**
   - Show banner if: `isEULocale(locale) === true` AND no consent stored in localStorage
   - Hide banner if: Not EU locale OR consent already given

5. **Accept handler:**
   - Store 'accepted' in localStorage: `localStorage.setItem('cookie-consent', 'accepted')`
   - Hide banner
   - Note: NEXT_LOCALE cookie is already set (strictly necessary, no consent required)

6. **Decline handler:**
   - Store 'declined' in localStorage
   - Hide banner
   - Note: Site still works, just disclosed that cookies exist

7. **UI design:**
   - Fixed position bottom of viewport (z-50 or higher)
   - Dark theme matching site (bg-card/90 with backdrop-blur)
   - Subtle top border gradient (like footer)
   - Max-width container, centered content
   - Two buttons: Accept (primary/magenta), Decline (ghost/secondary)
   - Link to privacy policy (optional)

8. **Translations:**
   - Use useTranslation() hook to get t() function
   - Access translations via t('cookieConsent.title'), etc.
   - Fall back to English if context unavailable (same pattern as Header)

9. **Animation:**
   - Use framer-motion for slide-up entrance
   - Fade out on dismiss

Layout:
```
[----------------------------------------------------------]
|                                                          |
|  Cookie Notice                                           |
|  We use cookies to remember your locale preference...    |
|                                                          |
|                        [Decline]  [Accept]               |
|                                                          |
[----------------------------------------------------------]
```

<task type="auto">
  <name>Task 2: Create LocaleSwitcher component</name>
  <files>src/components/locale-switcher.tsx</files>
  <action>
Create a client component for locale switching with these features:

1. **Props interface:**
   - `variant?: 'dropdown' | 'compact'` (dropdown for header, compact for footer/mobile)
   - `className?: string` for styling flexibility

2. **Get current locale:**
   - Use useLocale() hook from @/lib/i18n
   - Fall back to pathname parsing if context unavailable (same pattern as Header)

3. **Flag mapping:**
   - Import flags from country-flag-icons/react/3x2: US, NL, DK, AU, GB, IE
   - Map locale codes to flag components: { us: US, nl: NL, dk: DK, au: AU, uk: GB, ie: IE }
   - Note: UK uses GB flag (Great Britain)

4. **Locale labels:**
   - us: "United States"
   - nl: "Nederland"
   - dk: "Danmark"
   - au: "Australia"
   - uk: "United Kingdom"
   - ie: "Ireland"

5. **Switch handler:**
   - Set NEXT_LOCALE cookie: `document.cookie = \`NEXT_LOCALE=${newLocale}; path=/; max-age=31536000; samesite=lax\``
   - Replace current locale in pathname: `/us/services/seo` → `/nl/services/seo`
   - Use useRouter().push() for navigation (not replace, so user can go back)

6. **Dropdown variant (default):**
   - Trigger button shows current flag (20x15 px) + country name
   - Dropdown shows all 6 options with flag + country name
   - Use shadcn Select or simple native select with styled wrapper
   - Add ChevronDown icon to indicate dropdown

7. **Compact variant:**
   - For footer: Show all locale options as horizontal list of flag icons
   - Each flag is a clickable button (24x18 px)
   - Current locale has visual highlight (ring or underline)

8. **Styling:**
   - Match dark theme (bg-card, text-foreground)
   - Hover states with subtle animation
   - Accessible: aria-label on buttons, keyboard navigation

Note: Do NOT use shadcn DropdownMenu (not installed). Use native HTML select styled with Tailwind OR build simple custom dropdown with state.
  </action>

  </verify>

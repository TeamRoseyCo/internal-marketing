    Extract all Dutch translation strings from translations.ts and page-translations.ts and validate using LanguageTool API.

    **Validation approach:**
    1. Use LanguageTool public API (https://api.languagetool.org/v2/check) with language="nl"
    2. For each Dutch translation string, send to API and capture errors
    3. Apply context-aware filtering - ignore errors for:
       - Brand names: "Rosey Co.", "BunnyStream", "Meta", "Google Ads"
       - Technical terms: "SEO", "ROAS", "CTA", "ROI"
       - Common loanwords: "marketing", "social media", "dashboard", "leads"
       - Feature lists that use borrowed tech terms

    **Priority tiers for validation:**
    - Tier 1 (Critical): header, nav, footer, hero, cta sections
    - Tier 2 (High): services, whyUs, stats, faq sections
    - Tier 3 (Medium): meta descriptions, long-form content

    **Fix approach:**
    - For grammar errors: Apply LanguageTool suggested correction if unambiguous
    - For style errors: Review context before applying
    - For uncertain fixes: Note in VALIDATION.md for native speaker review

    **Mixed-language detection:**
    - Scan for English words/phrases that should be translated (not in allowed loanword list)
    - Flag: "Your Business", "Get More", "behind-the-scenes", etc.
    - Fix by translating to proper Dutch equivalents
